# Команда обновления code-check

## Контекст

CLI умеет устанавливать code-check, но у него нет отдельной команды `update` для явного перехода проекта на текущую версию пакета.

## Цель

Добавить `code-check update [project-path]`, которая обновляет `@human-horizon/code-check` до `latest` в `.lore/weft` и синхронизирует установленные Weft entry-файлы с этой версией.

## Детали реализации

- Использовать существующее определение менеджера пакетов: pnpm при наличии `pnpm-lock.yaml`, иначе npm.
- Для pnpm сохранить `--config.minimumReleaseAge=0`.
- Обновлять пакет с явным `@latest`.
- После обновления копировать pipeline entry-файлы из установленного пакета и удалять старые ненумерованные имена.
- Сохранять текущий порядок имён `01-` … `07-`.
- Обновить CLI usage и README.

## Критерии приёмки

- [ ] `code-check update` использует текущую директорию проекта по умолчанию.
- [ ] `code-check update <project-path>` работает с указанным проектом.
- [ ] Команда обновляет npm-зависимость до `@latest` и синхронизирует нумерованные pipeline-файлы.
- [x] `pnpm check` и `pnpm test` проходят (28 тестов).
