# Порядок пайплайнов code-check

## Контекст

Weft показывает независимые пайплайны по именам файлов. Текущие имена не задают нужный пользователю порядок.

## Цель

Упорядочить пайплайны в списке Weft числовыми префиксами. Автоматическую цепочку запуска не добавлять.

## Требуемый порядок

1. `generate-specs`
2. `generate-project-specs`
3. `generate-tests`
4. `generate-integration-e2e`
5. `generate-docs`
6. `generate-doc-translations`
7. `check-problems`

## Детали реализации

- При установке code-check копировать существующие entry-файлы в `.lore/weft/pipelines/code-check/` с числовыми префиксами `01-` … `07-` согласно списку.
- Обновить документацию и команды запуска, чтобы они ссылались на установленные имена.
- При повторной установке удалять известные прежние ненумерованные entry-файлы code-check, чтобы в проекте не оставались дубликаты.
- Не добавлять оркестратор и не менять поведение отдельных пайплайнов.

## Критерии приёмки

- [ ] Лексикографический порядок имён соответствует указанному списку.
- [ ] Повторная установка удаляет старые ненумерованные имена и копирует нумерованные entry-файлы.
- [ ] Документация и примеры запуска используют новые имена.
- [ ] TypeScript-проверка и тесты проходят.
